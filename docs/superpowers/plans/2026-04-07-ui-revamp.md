# UI/UX Revamp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the ad-hoc indigo color scheme and Inter font with a cohesive flat design system (teal primary, dark navy sidebar, Plus Jakarta Sans) across every widget and page in the app.

**Architecture:** Two new files establish the design system foundation — `AppColors` (all color constants) and `AppTheme` (ThemeData with Plus Jakarta Sans). Every widget and page is then updated to use `AppColors.*` tokens instead of raw hex literals. No logic or routing changes — purely visual.

**Tech Stack:** Flutter 3.41.4, Dart 3.11.1, google_fonts ^6.x (Plus Jakarta Sans), flutter_riverpod ^2.6.1
